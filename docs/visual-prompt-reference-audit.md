# 菜品生图视觉参考审计

目标：生图提示词必须从古籍做法和公开复原形态出发，避免把菜名拆成“食材拼盘”。本表用于审核 `DishVisualPromptService`、前端复原页提示词和 Python 兜底提示词。

## 审核原则

- 优先使用可核验古籍原文或权威古籍平台。
- 有现代复原图或报道时，只取成品结构，不照搬装饰。
- 证据弱的菜，用保守成品逻辑：熟制、切配、可入口、单一菜品，标注“推定”，不装成铁证。
- 提示词必须同时写“必须出现”和“必须避免”，尤其禁止整只动物、原始食材、概念拼贴。

## 公开实物图 / 复原图线索

- 蟹酿橙：泉州市人民政府“宋元海丝宴”报道图显示，成品是橙盅置于浅色瓷蒸盏中，上口露出蟹肉、蟹粉和蟹黄，并非整蟹摆盘。泉州申创美食之都英文官网也有多份白瓷碗托橙盅的宴席图。
- 蟹酿橙：杭州柏悦酒店、站酷摄影、昵图网等公开图同样呈现“橙盅 + 蟹粉蟹肉馅 + 橙盖/小碟”的结构；其中部分图会把整蟹放远处作背景，这不应进入生成主体。
- 槐叶冷淘：四川在线 2025 年杜甫草堂“草堂一味”报道有现场图，呈现槐叶汁和面的绿色凉面，面条可被手提起，调料另加。
- 玉糁羹：公开实物图多为现代复原或二手文章，形态有差异；提示词应以古籍“萝卜烂煮 + 米糁成羹”为准，避免被现代配菜图误导。
- 王太守八宝豆腐：公开图多为现代八宝豆腐，容易画成块状豆腐或麻婆豆腐；提示词应坚持《随园食单》“嫩片切粉碎、入浓鸡汁炒滚”的半流质豆腐碎。
- 荔枝腰子：杭州网“荔枝白腰子”报道有中国烹饪大师复原过程图，明确猪腰切菱格花刀、焯后自然卷曲，形如荔枝，且成菜偏白嫩。
- 莲房鱼包：福建日报“宋元海丝宴”图显示莲房鱼包为莲蓬/莲房状容器或孔洞结构，不是整条鱼配莲花；国博展览图也可见白色莲房孔洞形态。
- 驼蹄羹：公开素材有“驼蹄羹”羹汤图和陶盅图，但可信度不如古籍类菜；提示词只取“浓稠胶质羹汤、深碗/盖盅”结构，严禁完整脚掌。
- 炙羊肉：公开图常混入现代羊肉串和铁盘烤肉；提示词应按“带脂羊肉大片炙烤”处理，不采用串烧形态。
- 荷包鱼：公开图证据较弱，容易混入整鱼或油炸鱼；提示词保守锁定“鱼片或去骨鱼身包合成荷包状”。
- 浑羊殁忽：现成图片线索不足，按文献描述锁定“分切后的酿制肉菜切面”，不生成整只羊或整鹅。
- 东坡肉：实物图高度稳定，按规整酱红方块五花肉处理即可。

## 待继续核对

- `炙羊肉` 的本地数据写为《饮膳正要》“羊肉带脂、切大片、盐酱茴香、炙之”，但公开全文入口不易直接定位条目。当前提示词采用保守炙烤羊肉大片形态。
- `驼蹄羹` 公开资料多为烧尾宴二手说明，原始细节不足。当前提示词只锁定“浓稠胶质羹”，并强禁完整脚掌和猎奇器官形态。
- `荷包鱼` 公开文本证据弱于本地菜谱库。当前按“去骨鱼包合成荷包状”的保守视觉形态处理。

## 运行验证记录

- 2026-07-05：发现 `/api/generate-image` 使用 GET query 或终端脚本 POST 中文时，部分环境会把 `dishName=蟹酿橙` 解成 `???`，导致后端走默认提示词，真实生成结果跑偏成烤肉/鱼排加橙片。
- 修正：前端改为 POST JSON 并传 `dishId`；后端新增 `dishId -> 菜名` 映射，同时 GET 保留从编码 URL 恢复菜名的兜底。
- 2026-07-05：使用 `dishId: dish_001` 调 Agnes，返回 prompt 已包含 `steamed orange cup stuffed with crab roe and shredded crab meat`、`NO grilled meat`、`NO fish fillet`、`NO whole crab`。生成图为白瓷盏托橙盅，橙壳高边，内部可见蟹肉丝和蟹黄蟹粉，无整蟹、无蟹腿、无烤肉。当前剩余瑕疵是橙盖略像装饰翅膀，后续可继续细调为“单个橙盖半覆在橙盅上或斜靠盏边”。
