# 试点套餐设计

## 套餐一：博物馆互动展项

面向希望把饮食非遗、地方风物或历史生活方式做成互动体验的博物馆、非遗馆、城市展厅。

| 项目 | 内容 |
| --- | --- |
| 交付物 | 1 个主题展项脚本；20-40 个风味节点；3-5 道标杆复原菜；证据图谱；观众互动 H5/触屏页；分享证书；运营数据看板；馆员培训材料 |
| 周期 | 4-6 周，含选题、证据整理、界面配置、专家复核和现场联调 |
| 试点价区间 | 8 万-18 万元/馆/主题；硬件屏幕、布展施工、线下拍摄另计 |
| 采购人 | 馆长、展陈部、宣教部、地方文旅项目负责人 |
| KPI | 单次互动完成率 50%+；平均停留时长提升 30%+；展项分享证书领取 500+；馆方可复用内容资产不少于 30 条 |
| 毛利/成本假设 | 基础毛利 60%-70%；主要成本为内容结构化 2-3 万、专家复核 1-2 万、界面适配 2-4 万、模型与图片额度 0.5-1 万 |
| 下一步行动 | 约 30 分钟选题会，确认馆藏/地方主题；48 小时内产出 1 页概念样稿和 1 个可点击 demo |

## 套餐二：研学课程包

面向中小学综合实践、研学营地、非遗课堂和地方文化教育项目。

| 项目 | 内容 |
| --- | --- |
| 交付物 | 4-8 课时课程大纲；教师 PPT；学生任务单；证据卡牌；真假非遗题库；可操作复原菜谱；课堂展示模板；学习成果证书 |
| 周期 | 2-4 周，含课程设计、题库配置、教师试讲和一次迭代 |
| 试点价区间 | 3 万-8 万元/期/主题；线下师资、场地、食材和保险由采购方或合作方承担 |
| 采购人 | 研学机构产品负责人、学校综合实践负责人、少年宫/营地运营方、教育局项目承办方 |
| KPI | 课程完课率 85%+；学生作品提交率 70%+；家长/教师满意度 4.5/5；同主题复购或续用 1 次以上 |
| 毛利/成本假设 | 基础毛利 65%-75%；主要成本为课程设计 1-2 万、内容结构化 0.8-1.5 万、教具/题库配置 0.5-1 万、教师培训 0.5 万 |
| 下一步行动 | 选 1 个城市或节令主题，先做 2 课时样课；招募 1 个班或 30 人小营进行试讲验证 |

## 套餐三：餐饮文化新菜研发包

面向希望用历史文化故事支撑新品、宴席、城市限定菜单或节令营销的餐饮品牌。

| 项目 | 内容 |
| --- | --- |
| 交付物 | 1 个品牌文化选题；3-6 个新菜概念；每道菜的证据链、现代转译逻辑、命名建议、菜单文案、海报文案、短视频脚本；厨师试制清单；发布素材包 |
| 周期 | 3-5 周，含品牌访谈、证据复原、厨师共创、试吃反馈和营销素材定稿 |
| 试点价区间 | 5 万-15 万元/品牌/主题；后续拍摄、达人投放、门店物料和食材研发另计 |
| 采购人 | 餐饮品牌创始人、市场负责人、产品研发负责人、主厨或菜品总监 |
| KPI | 3 道以上可试制菜品；新品故事素材 20 条以上；门店上新周期缩短 30%；试点门店新品毛利率不低于品牌平均线；社媒内容完播/收藏高于日常内容 20% |
| 毛利/成本假设 | 基础毛利 55%-70%；主要成本为证据与文案 1.5-3 万、专家/顾问 1-2 万、厨师共创与试吃 1-3 万、设计与脚本 0.5-1.5 万 |
| 下一步行动 | 进行品牌菜单和客群诊断，选择 1 个历史线索或地方风物，7 天内提交 3 个新菜方向和证据样稿 |

## 统一试点边界

- 风味考古局负责证据链、内容资产、互动体验和传播素材，不单独承担硬件施工、线下招生、食品安全生产或广告投放结果。
- 涉及真实上菜和公开发布的内容，需要客户方厨师、食品安全负责人和专家复核共同确认。
- 所有试点默认沉淀为客户私有项目资产；经客户授权后，可抽象为行业案例和通用模板。
