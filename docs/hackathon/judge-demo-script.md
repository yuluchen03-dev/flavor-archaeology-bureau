# 评委演示脚本

## 90 秒黄金演示

### 三段锤版本

0-30 秒: 可信复原  
“我们不是生成菜谱，而是把一行古书变成可追溯、可制作、可传播的失传菜。”
点击“现场演示”，进入输入页。系统自动装入《山家清供》蟹酿橙线索，并锁定宋元、江南语境。
展示四步考据链: 古籍解码、食材校验、技法推演、成品复原。强调“每个结论都有出处、食材、技法和现代替代节点”。

30-60 秒: 传播闭环  
展示 40 道风味档案的星图索引。蟹酿橙是已复原节点，其他菜分为推荐复原和待考据。
打开轻量玩法，展示拍照认祖、每日复活、真假非遗、分享证书。说明普通用户也能参与传播。

60-90 秒: 落地价值  
“硬核考据负责可信，轻量玩法负责传播。”收束到文博展陈、研学课程、文旅风味地图和餐饮品牌文化新菜四个 B 端场景。

数字传承人和风味进化作为评委追问备用模块，不抢 90 秒主线时间。

## 3 分钟路演稿

0:00-0:25 问题钩子  
很多非遗不是消失在数据库里，而是消失在味觉里。古书里还留着片段，但普通人很难把它变成今天能理解、能制作、能传播的体验。

0:25-0:55 产品一句话  
风味考古局让用户输入古籍、古画或一段口述线索，AI 从文献、食材、技法和时代约束中复原失传菜，并生成今天可做、可学、可分享的版本。

0:55-1:50 现场 Demo  
一键装入《山家清供》蟹酿橙线索。界面展示流式考据链、证据图谱、置信度、复原图和现代做法。重点说明系统不是自由发挥，而是受知识图谱和历史约束。

1:50-2:20 体验扩展  
轻量玩法负责公众传播: 拍照认祖、每日复活、真假非遗和分享证书。数字传承人负责教学，味觉星图负责收藏和探索，风味进化负责文化创意。

2:20-2:45 商业落地  
我们优先做三类可付费试点: 博物馆互动展项 8 万-18 万元/主题，研学课程包 3 万-8 万元/期，餐饮文化新菜研发 5 万-15 万元/品牌。每单交付的不是概念页，而是证据包、互动页、课程或菜单素材和运营指标。

2:45-3:00 合作请求  
今天我们希望带走 3 个试点伙伴、2 位专家共建和愿意支持种子轮的产业投资人。我们的创新不是给传统文化套 AI 外壳，而是把文化规则变成 AI 推理规则，让消失的味道重新进入今天的生活。

## 评委追问 Q&A

Q: 这和普通 RAG 菜谱生成有什么区别？  
A: 普通 RAG 多是查资料后生成文本。风味考古局把朝代、地域、节令、食材可得性和技法转译做成约束链，并在界面展示证据图谱。核心是可追溯复原，不是会写菜谱。

Q: AI 会不会幻觉，编出不存在的古菜？  
A: 系统明确区分真实证据、推理结果、生成内容和缓存演示。低证据输入不会默认返回第一道菜，而是返回证据不足并要求补充线索。

Q: 没有 API key 时是不是假演示？  
A: 没有 key 时系统进入降级模式，界面和 JSON 都会标注本地规则、缓存演示或 placeholder。这样保证现场可用，同时不把降级结果伪装成真实外部模型输出。

Q: 数据量够吗？  
A: 当前是黑客松种子库，覆盖 40 道菜、108 条古籍文本节点、106 条权威文献条目、49 条图谱关系、8 条古籍片段和 150 张菜品背景图。下一阶段重点是结构化采集、专家校对和机构共建。

Q: 商业模式是什么？  
A: B 端优先，面向博物馆展陈、研学课程、文旅风味地图和餐饮品牌文化新菜研发。C 端轻量玩法负责传播和数据增长。
