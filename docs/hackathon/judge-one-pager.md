# 一等奖评审一页纸

## 一句话

风味考古局把古籍片段、食材可得性、古法技艺和生成式 AI 放进同一条可审计证据链，让失传菜从“文献里的名字”变成今天可看、可做、可学、可传播的文化产品。

## 痛点

很多非遗饮食不是没有资料，而是资料分散在古籍、地方志、口述和菜谱里。普通用户看不懂，文博机构难互动，餐饮和文旅很难把它转化成可复用内容。

## 方案

用户输入一段古籍、古画或口述线索，系统先做证据检索和规则校验，再输出复原菜、现代做法、证据图谱、AI 状态、数字传承人讲解、味觉星图和分享证书。

## AI 技术亮点

- 可追溯复原：输出 `citations[]`、原文短摘、来源链接、版权边界和专家复核状态。
- 证据门控：低证据输入返回 `insufficient`，不会为了演示默认给出第一道菜。
- 诚实降级：真实模型、规则 fallback、缓存演示和 placeholder 分开标注。
- 多模态扩展：VLM 识别、知识图谱、LLM 推理和图片生成使用统一元数据描述。

## 现场可验证点

1. 点击“现场演示”，自动装入《山家清供》蟹酿橙线索。
2. 结果页展示四步考据链、复原图、证据图谱和 AI 状态标签。
3. 输入弱线索时，系统返回证据不足而不是硬编结果。
4. 味觉星图能从 40 道风味档案继续复原指定菜。
5. 无外部 API Key 时仍可演示，但界面明确标注降级状态。

## 落地路径

- 文博展陈：把单向展板变成“输入线索、复活菜品”的互动装置。
- 研学课程：输出证据包、讲义、问答和实践菜谱。
- 文旅城市：做城市风味地图和节令食俗活动。
- 餐饮品牌：用可追溯历史故事研发文化新菜和营销素材。

## 评奖关键词

创新性：文化规则不是装饰，而是 AI 推理约束。  
完成度：输入、复原、教学、星图、轻量玩法、分享形成闭环。  
可信度：来源、置信、降级、拒答和版权边界可审计。  
商业性：B 端展陈/研学/文旅/餐饮优先，C 端玩法负责传播增长。
