# 可信边界与安全说明

## 真实 AI、规则降级与缓存边界

| 类型 | 说明 | 前端/接口标注 |
| --- | --- | --- |
| 真实 AI | 已配置外部 LLM/VLM/图片模型并成功返回 | `generated` / “真实 AI” |
| 规则降级 | 没有 key、网络失败或模型输出结构不合法时，使用知识图谱和关键词规则 | `degraded` / “降级” |
| 本地规则 | 不需要外部模型的确定性功能，例如星图状态或部分题库逻辑 | `local` / “本地规则” |
| 缓存演示 | 为保证评委路径不中断的已审核蟹酿橙样例 | `cached` / “缓存演示” |
| placeholder | 图片模型失败时的本地占位图 | `degraded` + `fallbackReason` |

## 低置信拒答

系统不再把任意线索默认映射到第一道菜。弱线索会返回:

```json
{
  "evidenceStatus": "insufficient",
  "needsMoreClues": true,
  "fallbackReason": "未能从线索中匹配到可信菜品"
}
```

这样可以避免“为了演示而硬编菜”，也方便评委看到系统的可信边界。

## 幻觉控制

- 古籍原文、食材、技法和朝代地域作为证据节点展示。
- 生成式图片和文本不会被包装成史实。
- 真假非遗玩法用于教育用户识别 AI 幻觉。
- 文档明确说明当前数据规模和种子库属性。

## 安全默认值

- 后端端口默认为 `3001`，前端默认 API base 为 `http://localhost:3001/api`。
- `JWT_SECRET` 在 `.env.example` 中明确要求替换；Docker Compose 使用环境变量注入，未设置时不会启动。
- `CORS_ORIGIN` 可配置，演示默认允许 `http://localhost:5173`；生产环境未设置时后端会拒绝启动。
- 请求体限制保留为 10 MB，适合图片 base64 演示但不适合无限制上传。
- `/api` 默认启用轻量 rate limit，演示值为每 IP 每分钟 120 次，可通过 `RATE_LIMIT_*` 环境变量调整。

## 现场失败策略

| 失败点 | 策略 |
| --- | --- |
| 后端未启动 | Result 页展示缓存演示并标注 |
| 流式考据中断 | 切换缓存演示或证据不足结果 |
| 图片模型失败 | 返回 degraded placeholder，不伪装成生成图 |
| VLM 未配置 | 返回本地视觉规则证据 |
| 线索过弱 | 返回证据不足和补充建议 |
