# 风味考古局 TRAE CN 黑客松评审材料

## 项目定位

风味考古局是一套可审计的中国非遗风味复原引擎。它不是普通 AI 菜谱生成器，而是把古籍片段、食材可得性、技法转译、朝代地域约束和生成式内容放进同一条可见证据链。

## 现场推荐路径

1. 首页点击“现场演示 - 90 秒评委路径”。
2. 输入页自动装入《山家清供》蟹酿橙线索。
3. 展示流式考据链、证据图谱、复原图和 AI 状态标签。
4. 跳转味觉星图，说明 40 道风味档案如何组织。
5. 展示轻量玩法或数字传承人，说明传播和教育闭环。

## 一等奖叙事

核心创新不是“让模型写一份古菜谱”，而是把文化规则变成 AI 推理规则。评委应看到三个层次:

- 硬核可信: 证据图谱、置信度、低证据拒答、真实 AI 与降级状态分离。
- 体验完整: 输入、复原、教学、星图、轻量玩法、分享证书形成闭环。
- 落地清晰: 文博展陈、研学课程、文旅风味地图、餐饮品牌文化新菜研发。
